# Kiintrus Market

Dashboard prive pour les marchands Kiintrus.

## Deploiement Vercel

Ce dossier est prevu pour etre deploye comme un projet Vercel separe depuis le meme repository.

Configuration du projet Vercel `market.kiintrus.com` :

- Repository : `7h3P3rf3ct/kiintrus.com`
- Framework Preset : `Other`
- Root Directory : `market`
- Build Command : vide
- Output Directory : vide
- Install Command : vide

Ensuite, ajouter le domaine :

- `market.kiintrus.com`

La vitrine publique `kiintrus.com` reste sur le projet Vercel existant avec la racine du repository.
